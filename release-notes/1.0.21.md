## Downloads
- **ScreenDeck-Setup-1.0.21.0.exe**: installer (per-user, no admin needed)
- **ScreenDeck.exe**: portable, run without installing

Windows 10/11 64-bit. The .NET runtime is included.

## What's new
- **GPU capture for the live view** (experimental, off by default): turn on **GPU capture** in the live view toolbar to read the monitor through the GPU. It only updates when something changes, so it uses much less CPU. If it isn't available on your PC, the live view quietly uses the standard capture.
- **Lower CPU use**: monitor previews are captured more efficiently, the fade-out effect is drawn by the GPU, and nothing is captured while ScreenDeck is minimized or covered by the live view.
- Monitor names now stay with the right monitor after a restart or when monitors are plugged in or out.
- Moving ScreenDeck to another monitor by hand now makes that monitor the control monitor next time too.
- Fixed: in the live view, a click after switching apps could turn into an unwanted drag.
- Fixed: holding a number key moved the program over and over.
- Fixed: number keys and Enter could act on a program while you were using the options bar.
- Fixed: small fixed-size windows (dialogs) were stretched to full screen by **Maximize after move**.
- Fixed: programs moved between monitors with different scaling could end up in the wrong spot.
- Fixed: some program icons never appeared.
- A single unexpected error no longer closes ScreenDeck.

## 이번 버전
- **확대 보기 GPU 캡처**(실험 기능, 기본 꺼짐): 확대 보기 상단의 **GPU capture**를 켜면 GPU로 화면을 읽습니다. 화면이 바뀔 때만 갱신해 CPU를 훨씬 적게 씁니다. PC에서 지원되지 않으면 자동으로 기존 방식으로 캡처합니다.
- **CPU 사용량 감소**: 모니터 미리보기 캡처가 가벼워졌고, 페이드아웃 효과를 GPU가 그리며, ScreenDeck이 최소화되었거나 확대 보기에 가려져 있을 때는 캡처하지 않습니다.
- 다시 실행하거나 모니터를 꽂고 뺀 뒤에도 모니터 이름이 올바른 모니터에 유지됩니다.
- ScreenDeck 창을 직접 다른 모니터로 옮기면 다음 실행 때도 그 모니터가 제어 모니터가 됩니다.
- 수정: 확대 보기에서 다른 앱으로 전환한 뒤 클릭하면 원치 않는 드래그가 되던 문제
- 수정: 숫자키를 누르고 있으면 프로그램이 계속 다시 이동하던 문제
- 수정: 옵션 바를 조작하는 중에 숫자키·Enter가 프로그램에 적용되던 문제
- 수정: 크기가 고정된 작은 창(대화상자)이 **Maximize after move**로 전체 화면으로 늘어나던 문제
- 수정: 배율이 다른 모니터로 옮긴 프로그램의 위치가 어긋나던 문제
- 수정: 일부 프로그램 아이콘이 표시되지 않던 문제
- 예기치 않은 오류 한 번으로 ScreenDeck이 종료되지 않습니다.
