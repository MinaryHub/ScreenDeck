# ScreenDeck

멀티 모니터 환경에서 한 화면을 **제어 화면**으로 두고, 다른 모니터에 떠 있는 프로그램을
드래그 앤 드롭으로 옮기는 Windows 프로그램입니다.

## 사용법
1. `dist/ScreenDeck.exe` 실행 (설치 불필요, .NET 런타임 포함). 처음에는 주 모니터가 제어 화면이 됩니다.
2. 위쪽에 모든 모니터가 실제 배치대로 실시간 미리보기로 표시됩니다.
3. 모니터를 클릭하면 아래에 그 모니터에서 실행 중인 프로그램 목록이 나옵니다.
4. 프로그램 카드를 위쪽의 다른 모니터 미리보기로 끌어다 놓으면 그 모니터로 이동하고 전체 화면(최대화)됩니다.

| 기능 | 조작 |
|---|---|
| 이동 | 카드를 모니터 미리보기로 드래그 |
| 빠른 이동 | 카드 선택 후 숫자키 `1`–`9` |
| 메뉴 | 카드 우클릭 |
| 앞으로 가져오기 | 더블클릭 또는 `Enter` |
| 창 위치 확인 | 카드에 마우스를 올리면 미리보기에 위치 표시 |
| 제어 모니터 변경 | 상단 "제어 모니터" 선택 (설정 저장됨) |
| 최대화 끄기 | "이동 후 전체 화면" 해제 시 상대 위치와 크기 유지 |

테두리 없는 전체 화면 창(영상 플레이어, 게임 등)은 대상 모니터 전체를 채우도록 옮겨집니다.

## 제한
- 관리자 권한으로 실행된 프로그램은 ScreenDeck도 관리자 권한으로 실행해야 옮길 수 있습니다.
- 독점 전체 화면(Exclusive fullscreen) 게임은 이동되지 않을 수 있습니다.

## 빌드
```
cd src/ScreenDeck
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -o ../../dist
```
.NET 9 SDK 필요. macOS/Linux에서도 크로스 빌드됩니다 (`EnableWindowsTargeting`).
